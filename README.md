# CppClass_Project

### 说明

environment-test：开发环境配置检测

cpp-training：实验课练习任务

WorkProject-SportCar：大作业跑车

 - 支持指令：M, L, R, F, B

 - 各指令生效如下表

   |  ---   |    M    |           L            |           R            |
   | :----: | :-----: | :--------------------: | :--------------------: |
   | Normal | 前进2格 |     左转再前进1格      |     右转再前进1格      |
   |   B    | 后退2格 |     右转再后退1格      |     左转再后退1格      |
   |   F    | 前进4格 | 前进1格，左转再前进1格 | 前进1格，右转再前进1格 |
   |   BF   | 后退4格 | 后退1格，右转再后退1格 | 后退1格，左转再后退1格 |

WorkProject-Bus：大作业公交车

- 支持指令：M, L, R, F, B

- 车长为2，坐标为车头坐标

- 各指令生效如下表

   | ---    | M       | L                      | R                      |
   | :----: | :-----: | :--------------------: | :--------------------: |
   | Normal | 前进1格 | 前进1格再左转          | 前进1格再右转          |
   | B      | 后退1格 | 后退1格再右转         |后退1格再左转          |
   | F      | 前进2格 | 前进2格，左转 | 前进2格，右转 |
   | BF     | 后退2格 | 后退2格，右转 | 后退2格，左转 |
